# Worktree Rescue 1.0.0

The first public release of Worktree Rescue — a local-first safety tool that
keeps independent, verified snapshots of uncommitted work across every Git
worktree your coding agents touch, and recovers it without touching your
repository.

## Highlights

- **Worktree inventory with evidence-based diagnosis.** Missing, possibly
  moved, prunable, drive unavailable and inaccessible worktrees are told apart
  instead of all being reported as "deleted".
- **Independent snapshots** of staged content, working-tree bytes, untracked
  files, deletions and renames in a SHA-256 content-addressed vault with
  atomic manifests. A snapshot is only *verified* after its content is
  re-hashed and committed.
- **Opt-in automatic protection** with quiet-period debouncing, a minimum
  interval and checkpoints during long sessions.
- **Recorder, timeline and diff viewer** built entirely from recorded data.
- **Safe recovery** into a separate folder by default, with a six-phase
  report; gated in-place restore with protection snapshots; read-only Git
  history search with provenance labels.
- **Risk Observatory** with severity, confidence and raw evidence.
- **Sandbox demo**, **retention and storage management**, **English and
  Simplified Chinese**, dark and light themes.

## Install

Download `Worktree Rescue_1.0.0_x64-setup.exe` below and run it. It installs
for the current user without administrator rights. Requires Windows 10 21H2+
or Windows 11 (x64), WebView2 and Git 2.31+.

The installer is **not code-signed** yet; Windows SmartScreen may ask for
confirmation. Verify the download with the SHA-256 checksum listed in this
release.

## Known limitations

- Submodule contents, Git LFS objects beyond the working-tree bytes, and
  files outside a sparse checkout are not captured (reported as partial
  support).
- In-place restore covers regular files only: deletions are not replayed and
  symbolic links are not recreated; the Git index is never modified.
- Sensitive files, when you opt in to capturing them, are stored unencrypted
  in the local vault (protected by your Windows account).
- Windows is the only packaged platform in 1.0; the core is portable and its
  tests run on Linux in CI.

## Verification performed for this release

- 49 Rust tests against real temporary Git repositories, including
  repository-fingerprint tests proving inventory, snapshots, verification,
  forensic scans, previews, retention and recovery leave the working tree,
  index, HEAD, refs, reflogs and stash byte-identical.
- 14 UI tests (navigation, empty, loading and error states, long-list
  virtualization, in-place restore confirmation, language switching,
  dictionary parity).
- The packaged installer was installed and the app exercised end to end on
  Windows 11 during a recorded 40-minute multi-agent session.
